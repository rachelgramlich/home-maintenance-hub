# Naming standards (household Streamlit hubs)

| App | Display title | Repo | Package | Env prefix |

| Home maintenance | Home Maintenance Hub | `home-maintenance-hub` | `home_maintenance_hub` | `HOME_MAINTENANCE_HUB_` |
